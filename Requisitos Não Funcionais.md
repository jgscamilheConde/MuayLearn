# Requisitos Não Funcionais — Muay Learn

## 1. Introdução

Os requisitos não funcionais definem características relacionadas à qualidade, segurança, desempenho, usabilidade e manutenção do sistema Muay Learn.

Diferentemente dos requisitos funcionais, eles não descrevem diretamente uma funcionalidade específica, mas estabelecem como o sistema deverá funcionar.

---

## 2. Requisitos Não Funcionais

### RNF01 — Usabilidade

O sistema deve possuir uma interface simples, intuitiva e de fácil compreensão para usuários iniciantes.

---

### RNF02 — Responsividade

O sistema deve adaptar sua interface para diferentes tamanhos de tela, incluindo computadores, tablets e smartphones.

---

### RNF03 — Segurança de senha

O sistema deve armazenar as senhas dos usuários utilizando mecanismos adequados de proteção, evitando o armazenamento de senhas em texto simples.

---

### RNF04 — Controle de acesso

O sistema deve controlar o acesso às funcionalidades de acordo com o tipo de usuário.

O aluno não deve possuir acesso às funcionalidades exclusivas do administrador.

---

### RNF05 — Desempenho

O sistema deve apresentar suas principais páginas e funcionalidades de maneira rápida e eficiente, evitando tempos de espera desnecessários.

---

### RNF06 — Disponibilidade

O sistema deve estar disponível para acesso aos conteúdos sempre que o serviço estiver em funcionamento.

---

### RNF07 — Manutenibilidade

O código-fonte deve ser organizado de maneira que futuras alterações, correções e implementações possam ser realizadas com facilidade.

---

### RNF08 — Escalabilidade

A estrutura do sistema deve permitir a inclusão futura de novos conteúdos, usuários, aulas, níveis e funcionalidades.

---

### RNF09 — Compatibilidade

A aplicação web deve funcionar adequadamente nos principais navegadores modernos.

---

### RNF10 — Legibilidade

Os conteúdos educacionais devem ser apresentados de maneira clara, organizada e legível para facilitar o aprendizado.

---

## 3. Resumo
